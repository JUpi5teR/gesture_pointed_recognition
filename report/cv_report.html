基于MediaPipe + YOLOv8 + Kalman滤波的无接触式人机交互系统

汇报人: 张英鹏 班级: 人工智能2302 日期: 2026年6月

项目概述

摘要：本项目设计并实现了一套基于计算机视觉的无接触式人机交互系统。用户通过指尖指向目标物体，系统利用YOLOv8进行实时目标检测，结合MediaPipe手部关键点检测计算指向方向，通过角度得分筛选候选目标。指尖在目标区域停留数秒后触发确认弹窗，用户通过点头/摇头进行确认或取消，确认后系统对目标进行持续跟踪，摇头即可释放锁定。系统核心由有限状态机驱动，融合了Kalman滤波平滑跟踪、指数衰减停留计时器、Pose骨架头部姿态识别等多项技术。

MediaPipe手部关键点检测

系统采用MediaPipe Hands框架进行手部关键点检测。MediaPipe Hands是一个基于机器学习的单手21个3D关键点检测器，采用两阶段流水线：首先通过手掌检测器定位手部区域，再通过关键点回归模型输出21个手部关键点坐标。

在本系统中，MediaPipe Hands的配置参数为：最大检测手数设为2(支持双手操作)，检测置信度阈值0.5，跟踪置信度阈值0.5。同时系统支持向后兼容MediaPipe Tasks API，当检测到新版MediaPipe时自动切换至PoseLandmarker接口，保证了跨版本兼容性。

关键点标注

MediaPipe Hands定义的21个关键点中，本系统特别关注以下关键点组合用于手势判定：

  WRIST       = 0   (手腕)
  THUMB_TIP   = 4   (拇指尖)
  INDEX_TIP   = 8   (食指尖)
  MIDDLE_TIP  = 12  (中指尖)
  RING_TIP    = 16  (无名指尖)
  PINKY_TIP   = 20  (小指尖)

指尖指向算法

凸包分析(Convexity Defects)

本系统在MediaPipe原始手部关键点的基础上，进一步通过凸包分析(Convexity Defects)对指尖位置进行精确定位。算法流程如下：

1. 从二值化手部轮廓中提取凸包(Convex Hull)
2. 计算凸包与原始轮廓之间的凸性缺陷(Convexity Defects)
3. 凸性缺陷的最深点即为指尖候选位置
4. 基于深度筛选：缺陷深度超过平均深度50%的保留为有效指尖

贝塞尔曲线平滑方向向量

在贝塞尔平滑算法上，本系统采用了基于自适应采样的二次贝塞尔曲线平滑方法：对凸包采样点进行步进式最大偏差采样(Step=70px, D=7px)，然后对每三个连续点拟合二次贝塞尔曲线，生成平滑的指尖方向向量。该方法相较于直接使用原始轮廓点，具有以下优势：

- 抗噪性强：有效抑制帧间抖动
- 方向稳定：确保指向方向的连贯性
- 计算高效：仅需O(n)复杂度

目标选择算法

系统采用基于角度与距离的综合得分算法(choose_target_2d)筛选指尖指向的物体。该算法在经典视线投射(ray-casting)方法的基础上，加入了对物体尺寸和指尖垂直偏移的归一化处理：

1. 计算食指指尖与指根的向量方向: dv = tip - base
2. 对每个YOLO检测到的物体:
   a. 计算物体中心相对指尖的方向向量: vec = center - tip
   b. 计算dv与vec的夹角theta = acos(dot(dv, vec))
   c. 如果theta > 30度，直接丢弃(角度阈值)
   d. 计算垂直偏移惩罚: perp = |vec x dv|
3. 得分公式:
   score = max(0, cos(theta)) * max(0, 1 - perp / (diag * dist_coeff))
   - cos(theta): 角度越接近0得分越高
   - 垂直偏移归一化: 偏移越小得分越高
4. 选择得分最高的物体作为目标

本算法在传统射线检测(ray-casting)的基础上，创新性地引入了物体尺寸归一化因子：使用物体对角线长度来归一化垂直偏移，使得大物体和小物体在选择时具有公平性。

停留确认机制

停留确认机制是本系统的核心交互逻辑。指尖指向目标后，需要在目标区域停留超过设定阈值(默认1.5秒)才能触发确认弹窗。为应对实际使用中的手部抖动和短暂偏移问题，本系统设计了带指数衰减和容忍窗口的停留计时器(TargetDwellTracker)：

算法特点

1. 停留计数(Dwell Count):
   - 目标在区域内: 每帧计数 +1
   - 目标离开区域 < 容忍时间(0.3s): 计数不变(容忍窗口)
   - 目标离开区域 > 容忍时间: 计数按指数衰减(rate=0.5/帧)
   - 计数衰减至最低保持阈值(30%)以下: 彻底清零

2. 确认弹窗(Confirm Popup):
   - 停留计数达到阈值(1.5s * 30fps = 45帧)后触发
   - 在目标位置绘制黄色圆环，进度条逆时针旋转
   - 超时(5s)自动取消，释放锁定回到IDLE

优势

传统的阈值计数方法在指尖短暂离开目标区域时会立即清零，导致用户需要反复定位。本算法通过容忍窗口和指数衰减的组合，显著提升了系统的可用性和鲁棒性，尤其在手部轻微抖动时表现优异。

头部姿态控制

基于Pose骨架的Pitch/Yaw估计

头部姿态识别采用MediaPipe PoseLandmarker获取人体33个姿态关键点，利用鼻尖(0)、左肩(11)、右肩(12)三个关键点计算头部Pitch(俯仰)和Yaw(偏航)角度：

1. 计算肩部中点: shoulder_center = (L_shoulder + R_shoulder) / 2
2. 计算颈部向量: neck = nose - shoulder_center
3. 分解颈部向量:
   - 沿肩部方向的分量 = lateral_component
   - 垂直于肩部的分量 = forward_component
4. Pitch(俯仰角):
   - angle_from_up: 颈部向量与垂直方向的夹角
   - ratio_pitch: 基于颈长/肩宽比偏离校准值的角度
   - 最终pitch = max(angle_from_up, ratio_pitch)
5. Yaw(偏航角):
   - yaw = atan2(lateral_component, forward_component)

自动标定机制

系统在上电后自动进行15帧的标定，记录用户自然姿态下的颈长/肩宽比(neck_shoulder_ratio)作为参考基准。该标定值采用指数移动平均(EMA)进行平滑更新，alpha=0.3，使得标定结果对单帧噪声具有鲁棒性。

点头/摇头判定

- 点头: pitch > 18度(低头) 后 pitch < 8度(抬头) = 完成一次点头
- 摇头: yaw < -12度(左摆) 后 yaw > 12度(右摆) = 完成一次摇头

YOLOv8目标检测

系统采用Ultralytics YOLOv8n(Nano版本)作为目标检测引擎。YOLOv8是You Only Look Once系列的最新迭代，采用Anchor-Free设计理念，将目标检测建模为回归问题：

- 输入尺寸: 640x640
- 置信度阈值: 0.35
- 模型类型: yolov8n.pt (约6MB, 适合实时场景)
- 推理后端: PyTorch (可选CUDA GPU加速)

YOLOv8采用C2f模块替代了YOLOv5中的C3模块，引入了更丰富的梯度流信息，在保持轻量化的同时提升了检测精度。系统仅保留边界框坐标、置信度和类别标签三个输出字段，用于后续的目标选择与跟踪。

Kalman滤波跟踪

当用户通过点头确认选中目标后，系统进入跟踪(Tracking)阶段。为实现平滑的跟踪效果并应对短暂遮挡，本系统设计了双通道Kalman滤波器(KalmanTracker + TargetTracker)：

双通道设计

通道1 - 2D点跟踪器:
  - 状态: (x, y, vx, vy) 二维位置+速度
  - 过程噪声: 0.05
  - 测量噪声: 2.0

通道2 - 4D边界框跟踪器:
  - 状态: (x1, y1, x2, y2) 边界框四维
  - 过程噪声: 0.02
  - 测量噪声: 5.0

跟踪闭环

1. 正常跟踪: 检测到目标时，更新Kalman状态并显示实时位置
2. 目标丢失: 目标点消失，记录最后已知位置
3. 重捕机制: 基于最后位置和边界框尺寸动态扩大搜索半径
4. 重新捕获: 物体重新出现时，目标点立即恢复

状态机设计

系统的整个交互流程由五状态有限状态机(Finite State Machine)驱动。状态定义在utils.py的SystemState枚举类中：

IDLE
空闲待命
→
DWELL_WAIT
停留等待
→
CONFIRMING
确认弹窗
→
TRACKING
持续跟踪
→
UNLOCKING
解锁释放

状态迁移规则

IDLE → DWELL_WAIT: 指尖指向某一YOLO检测到的物体，停留计时器开始累加

DWELL_WAIT → CONFIRMING: 停留计数达到阈值(1.5s)，在目标位置弹出黄色确认圆环

CONFIRMING → TRACKING: 用户点头确认，系统锁定目标并进入连续跟踪

CONFIRMING → IDLE: 用户摇头取消，或超时(5s)自动取消，回到空闲

TRACKING → UNLOCKING: 用户摇头，触发解锁流程

UNLOCKING → IDLE: 清理所有跟踪状态、计时器、Kalman状态，回到空闲

交互流程演示

步骤1：面向摄像头，手部指向目标物体区域。系统实时显示手部21个关键点和YOLO检测框。

步骤2：指尖对准目标物体，状态由IDLE切换为DWELL_WAIT，停留进度条开始增长(百分比显示)。

步骤3：进度条达到100%时触发确认弹窗，在指尖位置绘制黄色圆环进度条，显示"Nod=OK Shake=Cancel"提示。

步骤4-A(确认)：用户点头(Nod)确认，状态切换为TRACKING，目标框变为红色并进行持续跟踪。

步骤4-B(取消)：用户摇头(Shake)取消，系统回到IDLE空闲状态。

步骤5(解锁)：在TRACKING状态下摇头，目标解锁，系统回到IDLE。
